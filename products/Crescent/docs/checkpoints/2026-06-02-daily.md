## 二、技术选型（已确认）

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 向量数据库 | Chroma | 轻量 Python 原生，单机够用 |
| Embedding | BAAI/bge-large-zh-v1.5 | MTEB 中文榜单最高 |
| Agent 框架 | LangChain ReAct → LangGraph | 先简单后复杂 |
| LLM | deepseek-v4-flash | 已有 API Key，便宜 |
| 联网搜索 | DuckDuckGo (免费) | 不够再换 Tavily |
| 存储 | JSON 文件 | 单用户够用，暂不引入 SQLite |
| Agent max_iterations | 5 | 防止死循环 |
| Memory window | 10 轮 | ConversationBufferWindowMemory |
| Chunk size | 500 / overlap 50 | 初始值，后续实验调优 |

## 四、遇到的问题 & 解决方案

| 问题 | 原因 | 解决 |
|------|------|------|
| 仪表盘全部 "-" | Flask 绑 `127.0.0.1`(IPv4)，浏览器连 `::1`(IPv6) | 改 `HOST="0.0.0.0"`，杀僵尸进程重启 |
| 两个进程占 5000 端口 | 旧服务器未 kill 干净 | `powershell Stop-Process` 强杀 |
| home.html 编辑失败 | 原文件含不可见字符/tab/空格混合 | 用 Write 全部重写 |
| pip 装错 Python | 系统有 Python 3.9 和 3.14 两套 | 用 `python -m pip` 指定正确解释器 |
| 模型名写错 | 默认填了 `deepseek-chat` | 改为 `deepseek-v4-flash` |
