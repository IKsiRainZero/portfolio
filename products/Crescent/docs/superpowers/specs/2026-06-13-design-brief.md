# 前端重构 & 三合一融合 — 设计 Brief

> shape 产出 | 2026-06-13 | 架构级 | 4阶段 × 6页面
> 输入：PRODUCT.md v2 + 设计架构文档 v4 + 4轮反馈

## 1. Feature Summary

将 3 个独立应用（portfolio-app、cv-lab、portfolio-site）合并为单一 Flask 应用 `portfolio-main`，同时将前端从"浅色 SaaS 默认风格"重构为"深色构造主义"设计系统。这不是换皮肤——是将系统的内部结构（模块依赖、数据流、追溯链）暴露为视觉元素，让"透明性"从宣言变成可感知的界面。

## 2. Primary User Action

用户进入 Landing → 30秒内感知到"这是一个活的、在自我审视的系统" → 导航到 Dashboard 查看系统健康 → 下钻追溯链理解"为什么这个评分是这个数字" → 进入 CV Lab 上手实践算法 → 浏览知识库理解方法论。完整的"认知→探索→理解"弧线。

## 3. Design Direction

**Color strategy: Committed（构造主义深色基底，30-60% 表面承载品牌色身份）**

覆盖 PRODUCT.md 的 Restrained 默认——这是一个身份驱动的产品，深色基底本身就是品牌陈述。

**Theme scene sentence:**
"一个工程师在凌晨1点打开 Dashboard，房间只有屏幕的光。他需要快速判断系统健康状态。关键告警在黑暗中清晰可见，微光替代刺眼高亮，结构线在深邃背景上像精密仪器的刻度。"

**Anchor references:**
- 蓬皮杜中心（结构暴露在外，管道即美学）
- Linear（暗色产品 UI 的精确性标杆——一致的组件词汇、克制的色彩、信息密度恰好的间距）
- Stripe Dashboard（数据叙事——不是展示数字而是讲述"发生了什么"）

**色彩系统（从架构文档 v4 第6.4节）：**

| CSS 变量 | 色值 | 语义 | 使用场景 |
|----------|------|------|----------|
| `--bg-deep` | `#0f0f1a` | 可信、稳定 | 全局背景 |
| `--bg-layer-1` | `#1a1a2e` | 评估引擎层 | 面板背景 |
| `--bg-layer-2` | `#222240` | 元评估层 | 卡片背景 |
| `--bg-layer-3` | `#2a2a4a` | 展示层 | hover/active 态 |
| `--steel-blue` | `#3b82f6` | 数据、连接、逻辑 | 链接、活跃态、轨道线 |
| `--rust-red` | `#c44536` | 危险、紧急 | P0告警、评分<0.5 |
| `--copper-green` | `#00b4d8` | 成功、完整 | 评分>0.9、系统正常 |
| `--amber` | `#f59e0b` | 警告、过渡 | P1告警、评分0.5-0.7 |

**字体系统：**
- Inter（标题 + 正文）— 本地托管 `static/fonts/`
- JetBrains Mono（数据/代码/时间戳）— 本地托管

**磨砂玻璃约束：**

`backdrop-filter: blur()` 仅限以下三处使用，其他地方用 `background: rgba(26,26,46,0.95)` 纯色替代：
1. 追溯面板（滑出时）
2. 评分卡 hover 态
3. Landing 入口节点 hover 态

**依赖原则：**

不引入任何未在本文档明确列出的第三方前端依赖（npm 包或 CDN）。日期格式化用原生 `Intl`，动画用 CSS transition/animation，HTTP 请求用原生 `fetch`。Chart.js（已有）和 Three.js（P3 可选）是仅有的例外。

## 4. Scope

| 维度 | 决策 |
|------|------|
| **阶段覆盖** | 全部四阶段（P0→P1→P2→P3）一次性规划 |
| **精细度** | 架构级 brief——定义设计系统宪法 + 每页布局策略 + 关键状态。craft 遇到 brief 未覆盖的决策点必须停下来问，不能自行脑补 |
| **页面覆盖** | 全部 6 类页面 |
| **交互性** | 静态视觉方向 + 交互行为定义（不做可交互原型） |
| **时间意图** | 生产就绪——这是实际发布的作品集，不是探索 |

### 执行顺序

**结构合并独立执行，使用旧样式完成验证。** 确认单端口运行正常、所有 Blueprint 注册无误、173 个测试通过后，再启动 P0 视觉重构。不边合边美——同时处理两个变量无法定位根因。

结构合并时前端 DOM 预埋轨道网络 SVG 容器（`<svg id="orbit-network" style="display:none">`），P1 阶段用 `_build_import_graph()` 产出的 JSON 填充并切换为可见。

### 四阶段定义

| 阶段 | 内容 | 触发条件 |
|------|------|----------|
| **P0** | CSS 变量体系 + 字体本地化 + 磨砂玻璃克制使用 + motion-safe/motion-reduce 系统 + 深色主题基底 | 基础。所有后续阶段的前提 |
| **P1** | 追溯链 SVG + `_build_import_graph()` + 轨道网络 SVG + 三级导航结构 | P0 完成 |
| **P2** | 微动画6种 + 水印开关(Esc) + data-track 事件委托 + 统一导航 | P1 完成 |
| **P3** | 3D 背景粒子(WebGL检测+降级) + Spline 试验(可选) | P2 完成，且性能基线保持 |

### 每阶段验收门禁
- P0: FCP ≤ 1.5s，`perf_check.sh` 通过，所有页面可渲染
- P1: 追踪覆盖率 ≥ 70%，轨道线基于真实 import graph JSON（JSON 为空则隐藏）
- P2: 6种动画全部可降级，`data-track` 事件量不下降 >30%
- P3: WebGL 不可用时自动降级，不阻塞核心功能

## 5. Layout Strategy

### 5.1 统一导航：三级结构

```
L1（顶部固定）: Landing | 评估系统 | 知识库 | CV实验室
    ↓ 进入功能区后
L2（侧边栏）: 当前功能区内的子页面
    ↓ 页面内
L3（锚点/Tab）: 追溯链、评分卡折叠区、深层内容
```

- L1 始终可见（`position: sticky`），4个入口对应4大功能区
- L2 随功能区切换内容（评估系统：总览/模块详情/Agent追踪/元评估；CV实验室：Harris/SIFT/CNN）
- L3 为页面内深度导航（追溯面板、评分卡折叠区）

### 5.2 Landing（大门）

视觉层次：**品牌标记 → 品牌宣言 → 实时数据证明 → 三大入口**

```
┌──────────────────────────────────────────────┐
│  背景：深空(#0f0f1a) + 轨道网络SVG缓慢旋转     │
│                (120s/圈, ease-in-out)         │
│                                              │
│                   ○ (铜绿圆环, 24px)           │
│                                              │
│           "PORTFOLIO" (Inter Bold, 4rem)      │
│   一个人+AI+正确方法论，可以连续建造复杂系统     │
│   而不陷入混乱。                               │
│                                              │
│   ┌─评估系统─┐ ┌─知识库─┐ ┌─CV实验室─┐        │
│   │ 健康度   │ │ 方法论  │ │ 实践操作  │        │
│   │ 0.85    │ │ 论文    │ │ 可视化   │        │
│   └─────────┘ └────────┘ └──────────┘        │
│                                              │
│   系统当前健康度: 0.85 | 上次评估: 2h前        │
│   (服务端 Jinja2 渲染，非 API 调用)            │
└──────────────────────────────────────────────┘
```

- **品牌标记**：宣言上方1px粗铜绿色圆环（24px），内部小写"P"（Inter Bold, 12px），页面加载时 `scale(0.8) → 1`（1.5s, ease-out-expo）。整个系统唯一的纯品牌元素。
- **轨道旋转**：周期 120s/圈，ease-in-out，无停顿。不响应 hover 加速——轨道有自己的节奏。
- 三个入口节点使用磨砂玻璃卡片，hover 时 `translateY(-4px)` + 对应轨道高亮
- **底部实时数据条**：服务端 Jinja2 模板渲染时注入（读取 `heartbeat.json` 时间戳和总评分，在 Flask 渲染 Landing 模板时写入 HTML），确保 FCP 不受 API 请求影响。两步检查：heartbeat 正常 + summary 正常 → 显示评分和时间；heartbeat 正常 + summary 失败 → "评估引擎运行中，数据暂不可用"；heartbeat 失败 → "评估引擎离线"（红色警告）
- 轨道网络 SVG 背景：`opacity: 0.08`，旋转周期 120s/圈。hover 入口节点时对应轨道 `opacity: 0.25`（不加速旋转，仅改变透明度）
- 移动端：品牌标记缩小至18px，三节点纵向堆叠，轨道动画隐藏

### 5.3 Eval Overview（评估总览）

视觉层次：**系统评分(大) → P0告警横幅 → 关键趋势 → 模块覆盖率**

```
┌──────────────────────────────────────────────┐
│  [系统总评分: 0.85]  [自指状态: L2正常]        │
│                                              │
│  ▓▓▓▓▓▓▓▓ P0告警横幅（有告警时出现，脉冲动画）  │
│                                              │
│  ┌─趋势线带标注点──────────┐ ┌─评分卡折叠区─┐  │
│  │                        │ │ L1 数据完整度 │  │
│  │    ╱╲    ╱╲           │ │ L2 安全审计  │  │
│  │   ╱  ╲╱╱  ╲╱         │ │ L3 元评估   │  │
│  │                        │ │  ...         │  │
│  └────────────────────────┘ └──────────────┘  │
│                                              │
│  背景：极细轨道网络线 (opacity: 0.12)           │
└──────────────────────────────────────────────┘
```

- 总评分数字大（`font-size: 3rem`），颜色动态：>0.9 铜绿 / 0.5-0.7 琥珀 / <0.5 锈红
- P0 告警横幅：`box-shadow` opacity 在 0.2-0.5 间脉冲（`.motion-safe` 下），红色左边框+锈红背景微光
- 趋势线标注点：hover 时显示 tooltip（时间+评分+触发事件），对应轨道短暂高亮
- 评分卡：默认 L1 展开、L2/L3 折叠。折叠区域有微弱渐变暗示"下面还有内容"
- 移动端：评分卡单列堆叠，趋势线下移

### 5.4 Eval Detail（评估详情）

视觉层次：**模块级下钻 → 建议列表 → 追溯面板（滑出）**

- 模块详情页=三层评分卡全部展开 + 建议列表（按 P0→P1→P2 排序）
- 建议项：hover 时左侧出现对应色细条（P0=锈红/P1=琥珀/P2=钢蓝），点击滑出追溯面板
- 追溯面板：从右侧滑出（300ms），磨砂玻璃背景，六环水平排列。hover 单环显示数据摘要，点击跳转到对应模块
- 追溯链水印：页面背景 `opacity: 0.08`，hover 指标时变为 `opacity: 0.6`

### 5.5 CV Lab（CV 实验室）

视觉层次：**算法选择 → 参数调整 → 实时可视化 → 结果解读**

- 左侧：算法选择（Harris / SIFT / CNN）+ 参数面板
- 右侧：可视化结果区——图像 + 叠加的特征点/边缘/激活图
- 算法计算为 CPU 密集型，结果缓存为静态文件（避免阻塞 Flask 请求线程）
- 设计系统复用评估 Dashboard 的 CSS 变量，但色温微调——背景更接近中性深灰（`--bg-layer-1`），减少"评估系统"的告警色彩

### 5.6 Knowledge（知识库）

视觉层次：**知识地图 → 文章列表 → 关联推荐**

- 知识地图：节点-边图，节点=文章/方法论卡片，边=引用/关联关系。基于知识库 JSON 文件渲染。
- 文章列表：标题 + 摘要 + 标签。hover 时对应知识地图节点高亮。
- 关联推荐：当前文章底部的"相关阅读"，类似双向链接。

### 5.7 Meta Eval（元评估）

视觉层次：**6项检查结果 → 宪法Metric状态 → 探测卡 → 跨验证结果**

- 6项检查：每项一个状态指示器（通过/警告/失败），颜色=铜绿/琥珀/锈红
- 探测卡：磨砂玻璃卡片，hover 展开显示详细决策逻辑。`data-track="probe_card_expand"` 事件委托。
- 跨验证结果：显示 CODE vs LLM 评分对比（Phase 3 接入 LLM Judge 后活跃）

## 6. Key States

### 全局状态

| 状态 | 视觉处理 |
|------|----------|
| **默认** | 深色基底 + 轨道线 `opacity: 0.12`，微动画正常运行 |
| **加载** | 骨架屏（不是 spinner）。骨架块颜色 `--bg-layer-2`，脉冲动画：`opacity 1.0 → 0.5 → 1.0`，周期 2s，ease-in-out。骨架屏使用与目标内容相同的布局结构，不显示文字只显示灰色块。数据到达后 200ms 内骨架屏淡出（`opacity: 1 → 0`）、内容淡入（`opacity: 0 → 1`） |
| **空态** | 评分卡显示"暂无数据" + 说明文字（如"评估引擎尚未运行，首次评估将在下一个整点触发"）。轨道线保持但全暗（`opacity: 0.04`） |
| **错误** | 对应卡片替换为琥珀色边框 + 错误摘要 + "查看日志"链接。不影响其他卡片渲染 |
| **影子模式** | 正常渲染 UI，但评分旁标记 `[SHADOW]` 灰色标签，写操作按钮 disabled + tooltip "影子模式下不可操作" |

### Landing 特定状态
- **首次加载**：轨道网络从 `opacity: 0` 淡入到 `opacity: 0.08`（1.5s），三个入口节点依次上浮（各延迟 200ms）
- **数据不可用**：底部实时数据条替换为静态宣言，不显示虚假数字

### Eval 特定状态
- **无告警**：告警横幅区域隐藏（不是显示"无告警"——节省垂直空间）
- **全部评分 >0.9**：总评分铜绿色，系统状态标签显示"健康"
- **追溯链断裂**：断裂处红色虚线 + 脉冲闪烁（`.motion-safe`），tooltip 说明断裂原因（"该 Span 已被清理为孤儿"）

### CV Lab 特定状态
- **算法计算中**：结果区显示骨架 + 进度条（基于预估计算时间），参数面板保持可交互
- **无图像上传**：显示示例图像选择器 + "或拖拽上传"的虚线框

## 7. Interaction Model

### 跨页面交互模式

**hover 三阶段：**
1. 瞬间（0ms）：元素 `z-index` 提升，确保不被相邻元素遮挡
2. 过渡（200ms）：`translateY(-2px)` + `box-shadow` 加深，背景微亮
3. 关联（200ms）：同一模块的轨道线高亮（`opacity: 0.12 → 0.4`），关联数据节点微微发光

**点击行为：**
- 评分卡：展开/折叠（L2/L3），`data-track="scorecard_toggle"`
- 建议项：滑出追溯面板（右侧，300ms ease-out），`data-track="suggestion_trace"`
- 追溯环：跳转到对应模块 Dashboard 页。**路由模式为 Flask 多页面（Jinja2 渲染），非 SPA。** 整页加载时先显示骨架屏（与 Loading 状态一致），数据通过 API 异步填充，提供视觉连续性。不使用前端路由库——保持零框架原则。
- 导航 L1/L2：当前页高亮（铜绿色下划线，2px），切换时整页加载+骨架屏，不使用 crossfade（Flask 多页面无法实现）

**键盘导航：**
- Tab 键遍历所有交互元素（焦点环：1px 钢蓝 `box-shadow`）
- Enter 键激活当前焦点元素
- Escape 键：关闭追溯面板 / 折叠评分卡 / 临时隐藏水印（P2）

**滚动行为：**
- 评分卡区域独立滚动（`overflow-y: auto`），页面其他部分固定
- 追溯面板打开时，背景内容 `overflow: hidden` 防止双重滚动

### 动画触发条件（不是循环播放）

| 动画 | 触发 | 停止条件 |
|------|------|----------|
| 呼吸 | 数据更新（beacon 返回新值） | 3s 后自动静止 |
| 涟漪 | hover 追溯环 | 鼠标离开 |
| 扫描线 | 元评估运行中（heartbeat 返回 `meta_eval_running: true`） | 元评估完成 |
| 抬升 | hover 评分卡/建议项 | 鼠标离开 |
| 汇聚 | hover 趋势图标注点 | 鼠标离开 |
| 断裂闪烁 | 追溯链检测到断裂 Span | 断裂修复或确认为永久 |

### motion-reduce 降级（所有动画包裹在 `.motion-safe`，降级在 `.motion-reduce`）

- 呼吸 → 静态显示
- 涟漪 → 直接高亮所有环
- 扫描线 → 隐藏
- 抬升 → 保留 shadow，取消 transform
- 汇聚 → 仅显示 tooltip
- 断裂闪烁 → 静态红色虚线

## 8. Content Requirements

### 每页微文案

| 页面 | 关键标签/文案 | 空态消息 | 错误消息 |
|------|-------------|----------|----------|
| Landing | "PORTFOLIO" + 宣言 + 三大入口标签 | "系统正在初始化，数据将在首次评估后显示" | heartbeat正常+summary失败: "评估引擎运行中，数据暂不可用"；heartbeat失败: "评估引擎离线"（红色警告）+ 最后心跳时间 |

### 动态数据范围
- 总评分: 0.00 - 1.00（两位小数）
- 建议数: 0 - 50+（超出折叠 + "查看全部"）
- 模块数: 10 - 30（取决于 DEFAULT_SCORE_CONFIGS 注册量）
- 追溯链长度: 0（断裂）到 6（完整六环）
- 轨道节点数: 由 `_build_import_graph()` 产出 JSON 决定

### 图像/媒体清单

| 角色 | 来源 | 格式 | 阶段 |
