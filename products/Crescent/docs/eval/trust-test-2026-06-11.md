## 教训

1. **DOM 销毁陷阱** — `innerHTML` 赋加载态会销毁所有子元素，任何依赖固定 DOM ID 的操作都会静默失败。这是 `<template>` 迁移（Command 4）中暴露的架构耦合问题。
2. **视觉 bug 摧毁信任** — sparkline 拉伸不是数据错误，但视觉效果足以让用户认为"整个系统有 bug"。视觉正确性是信任的必要条件。
3. **术语需要解释** — "Trace" 对非技术人员是陌生概念。一行说明文字即可消除困惑。
4. **30 秒信任法则是有效的** — 真人盲测在 60 秒内暴露了三个靠代码审查和自动化测试都没发现的问题。
