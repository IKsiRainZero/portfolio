用量控制

Agent 最大步数
取消步数上限后，Agent 可能在复杂任务中陷入长循环，导致单次对话耗时数分钟并大量消耗 API 额度。
每分钟速率上限
取消速率限制后，短时间大量并发请求可能触发 API 提供商的限流封禁，或产生意料外的高额费用。
单次对话轮数上限
取消轮数上限后，超长对话会累积大量上下文 Token，每次后续请求都携带完整历史，显著增加每次调用的成本。
单次会话 Token 上限
单次会话超过 Token 上限后，Agent 将自动中断并提示用户开启新会话。防止单次对话成本失控。
每日 Token 总上限
当日 Token 消耗超过此上限后，所有 Agent 对话将降级为 Mock 种子回复，次日 00:00 自动重置。
