# Console 技术栈

## 后端
- Python 3.x + FastAPI + uvicorn
- anthropic SDK (LLM 代理)
- SSE (Server-Sent Events) 流式推送
- pytest

## 前端
- React 18 + TypeScript + Vite
- CSS Modules + framer-motion
- 无状态管理库 (React state + context)

## 存储
- JSONL 每日 trace 文件 (.context/observability/traces/)
- 只读解析: STATUS.md, git log, session stubs, constitution
