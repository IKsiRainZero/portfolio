# Where_is_it — 设计规格

日期：2026-07-08 | 状态：待实施

## 概述

微信小程序，帮助用户记住日常物品位置，在遗忘发生前提醒。纯本地存储，零服务器。

## 技术栈

- 微信小程序原生（WXML + WXSS + JS/TS）
- 语音识别：`wx.startRecord` + 微信语音转文字
- 存储：`wx.setStorageSync`（初期），按需升级 SQLite 插件
- 定位：`wx.getLocation` + 地理围栏
- 提醒：`wx.requestSubscribeMessage` 模板消息
- Agent NLP：本地规则引擎（正则+关键词），保留 LLM 接口

## 架构

```
小程序（前端）
├── 语音/文字输入层
├── Agent（NLP 解析引擎）— 本地规则，保留 LLM 接口
├── 场景管理（定位自动 + 手动切换）
├── 提醒引擎（记忆曲线定时 + 事件触发）
├── 知识图谱（物品-位置-时间线）
└── 本地存储
```

纯本地，零服务器。不上传任何用户数据。

## 功能模块

### 1. Onboarding

- 授权：定位 + 麦克风 + 消息订阅
- 问卷（≤5 题，选择题，30 秒完成）：
  - 最常忘带什么？（多选：钥匙/手机/钱包/伞/其他）
  - 最容易忘的场景？（出门时/下班时/换地方时/其他）
  - 作息类型？（固定通勤/不固定/两者之间）
  - 提醒偏好？（轻度/中度/重度）

### 2. 主页

```
├── 顶部：场景标签 + 切换（🏠家 🚪大门 🏢公司 🚗车上）
│         定位自动切换，可手动改
├── 中部：物品卡片（最重要置顶）
│         · 物品名 + 图标
│         · 当前位置 + 上次更新时间
│         · [更新位置] [查看轨迹]
└── 底部：大语音按钮（按住说话），保留键盘入口
```

核心交互目标：更新位置 <3 秒。

### 3. Agent 解析引擎

- 意图识别：更新位置 / 查询位置 / 新增物品 / 添加提醒
- 实体抽取：物品名 + 位置名
- 规则体系 v1：句式模板匹配（"X放Y" → 更新，"X在哪" → 查询）
- 本地执行，毫秒级响应，免费，离线可用
- 保留 LLM 接口：`AgentLLM.parse(text) → {intent, entities}`

### 4. 提醒引擎

**通道 1：记忆曲线定时**
- 公式：R = e^(-t/S)，留存率降至 60% 触发提醒
- 级联间隔：首次 20min → 1h → 8h → 1d → 3d → …（每更新一次，间隔宽松一档）
- 频率等级可选（轻度/中度/重度）

**通道 2：事件触发**
- 离开"家"围栏 → 推送检查清单
- 离开"公司"围栏 → 推送检查清单
- 场景切换时触发对应物品清单

**防打扰**
- 同物品一天最多 N 次（按等级）
- 2 小时内不重复提醒同一物品
- 静默时段 22:00-08:00
- 用户标记"已处理"后当天不再弹

### 5. 知识图谱 / 时间线

- 物品位置变更历史列表
- 每次记录含：时间戳、位置、场景、来源（语音/手动）
- 可追溯、可审计

### 6. 数据模型

```
Items: id, name, current_location, last_updated, created_at, importance, icon
LocationHistory: id, item_id, location, timestamp, scene, source
Scenes: id, name, geo_fence, is_default, trigger_items[]
ReminderSettings: frequency_level, quiet_hours, geo_enabled, curve_enabled
OnboardingAnswers: common_items[], forget_scenarios[], schedule_type, reminder_preference
```

存储：`wx.setStorageSync`，10MB 够 3-5 年使用。

## 关键决策

- 不做通用物品追踪，聚焦"离开/换场景"时刻
- 编码成本 <3 秒，否则用户不用
- 提醒不打扰用户，分级可选
- 先采集个人数据再迭代功能
- 微信小程序 = 零安装分发 + 跨平台

## 验收标准

1. 核心物品（钥匙/钱包/手机/伞）能帮用户避免丢失
2. 首页一眼看到最重要物品位置 + 上次更新时间
3. 功能一目了然，引导明确，字号清晰
4. 所有数据本地存储，不上传任何云端
5. 提醒不过度打扰，频率分级可选

## 禁止

- 过度弹窗打扰用户
- 花哨 UI 妨碍可读性
- 云端存储用户数据
- 未经用户确认的 LLM 调用
